# Features: Stats options

One feature of the site design blocks shown across several designs: stats options. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

Stats are chosen and you are picking their treatment.

## The decision it settles

`statsTreatment` (row, tiles, inline spread) and `countUp`. Row under a hero, tiles as a band of their own, inline for details with labels.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 2 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `statsBar` | 2 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `cardStyle` | `deep` |
| `countUp` | `true` |
| `statsTreatment` | `row`, `tiles` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

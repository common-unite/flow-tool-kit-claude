# ExampleParentRecordPage

A parent record page: one record and what belongs to it, here a single fund, on the Customer Service theme.

**Built from:** a `Hero` with the fund's status badges and actions; an 8/4 `Section` with `Tabs` (Overview, Eligibility, Questions as `RichContent`) beside an `ActionCard` deadline and stacked `Facts`; a 6/6 `Section` with a vertical `Timeline` beside a `Quote`; and a closing `Callout`. The same page shape `/design-to-blocks` produces for a record page.

On a site the hero's heading and the facts read the record with `{{Field}}` merge fields; here they show sample content.

## On LWR

On an LWR site the conversion scripts place the same Sections and blocks in the Build Your Own (LWR) layout. The Customer Service header is Aura only.

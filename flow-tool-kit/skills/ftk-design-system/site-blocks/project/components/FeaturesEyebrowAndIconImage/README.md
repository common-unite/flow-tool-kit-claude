# Features: Eyebrow and icon image

One feature of the site design blocks shown across several designs: eyebrow and icon image. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

Cards need a small label above the title or an image used as the icon.

## The decision it settles

Whether each card carries an eyebrow (category, date) and whether its icon is an SLDS icon or a small image.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 1 block, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `cards` | 1 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `cardStyle` | `outlined` |
| `columns` | `3` |
| `hoverStyle` | `lift` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

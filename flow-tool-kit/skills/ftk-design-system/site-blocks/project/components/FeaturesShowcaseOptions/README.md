# Features: Showcase options

One feature of the site design blocks shown across several designs: showcase options. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

A hero should show a product or illustration beside the copy, either way round.

## The decision it settles

`reversed` and `imageFit`: which side the image sits on, and whether it keeps its natural shape.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 2 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `hero` | 2 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `backgroundGradient` | `off` |
| `footnoteAlign` | `center` |
| `headingAlign` | `center` |
| `imageFit` | `natural` |
| `reversed` | `true` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

# Features: Section layout

One feature of the site design blocks shown across several designs: section layout. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

The section heading's alignment and position against its content are undecided.

## The decision it settles

Heading and body alignment (left or center) and stacked versus split. Left for content pages, center for short feature bands.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 3 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `cards` | 3 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `arrangement` | `split` |
| `bodyAlign` | `center`, `left` |
| `cardStyle` | `outlined` |
| `columns` | `2` |
| `headingAlign` | `center`, `left` |
| `hoverStyle` | `lift` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

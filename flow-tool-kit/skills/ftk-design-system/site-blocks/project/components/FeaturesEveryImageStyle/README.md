# Features: Every image style

One feature of the site design blocks shown across several designs: every image style. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

A hero or image block has a picture and you are picking how the picture is framed.

## The decision it settles

`imageStyle`: clean for photos, elevated for screenshots, mascot for cut-out characters, deep or glow for one dramatic image.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 12 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `hero` | 12 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `backgroundGradient` | `off` |
| `footnoteAlign` | `center` |
| `headingAlign` | `center` |
| `imageFit` | `natural` |
| `imageStyle` | `clean`, `deep`, `elevated`, `flat`, `ghost`, `glow`, `gradient`, `inset`, `mascot`, `outlined`, `siderule`, `topbar` |
| `reversed` | `true` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

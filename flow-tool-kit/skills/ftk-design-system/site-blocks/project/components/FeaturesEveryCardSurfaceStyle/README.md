# Features: Every card surface style

One feature of the site design blocks shown across several designs: every card surface style. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

Cards are chosen and you are picking their surface.

## The decision it settles

`cardStyle`: outlined for honest choices, elevated for clickable options, ghost on gradients, joined for one idea in parts, deep or glow for a single feature card.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 11 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `cards` | 11 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `cardStyle` | `clean`, `deep`, `elevated`, `flat`, `ghost`, `glow`, `gradient`, `inset`, `outlined`, `siderule`, `topbar` |
| `columns` | `3` |
| `hoverStyle` | `lift` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

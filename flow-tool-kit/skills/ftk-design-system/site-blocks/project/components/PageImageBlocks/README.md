# Page example: Image blocks: photo, gallery and image settings on real content

A whole demo page, section by section with its column widths: image blocks: photo, gallery and image settings on real content. Use it as the starting shape for a page of that kind.

## Use it when

A client has strong photos and wants a page that shows the work (an impact page, an event recap).

## The decision it settles

How to use photos across a page without repeating one treatment: image styles, Ken Burns, parallax and a carousel in one rhythm.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 23 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `backgroundEffect` | `kenburns`, `parallax` |
| `backgroundGradient` | `off` |
| `backgroundOverlay` | `bottom`, `tint` |
| `badgePosition` | `top` |
| `blockHeight` | `band`, `standard`, `tall` |
| `bodyAlign` | `left` |
| `buttonAlign` | `left` |
| `contentPosition` | `bottom` |
| `countUp` | `true` |
| `entrance` | `cascade`, `rise`, `zoom` |
| `footnoteAlign` | `center` |
| `headingAlign` | `left` |
| `hoverStyle` | `lift`, `tint` |
| `imageFit` | `natural` |
| `imageStyle` | `clean`, `elevated` |
| `reversed` | `true` |
| `statsTreatment` | `row` |
| `width` | `full` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

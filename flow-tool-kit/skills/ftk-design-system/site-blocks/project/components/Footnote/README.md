# Footnote

The small line under a block's content (the `footnote` key in the Footnote pane).

**Maps to:** keys on any block, not a component of its own. The preview draws them on a bare Steps block so they are seen alone. Use them through a block's props: `<Hero footnoteAlign={...} />`.

## Settings

| Prop | Property Editor | Values |
| --- | --- | --- |
| `footnoteAlign` | Footnote: Footnote Alignment | `left`, `center`, `right` |
| `footnoteSize` | Heading | rich text |
| `footnoteGap` | Footnote: Space Above Footnote | `default`, `none`, `xxx-small`, `xx-small`, `x-small`, `small`, `medium`, `large`, `x-large`, `xx-large` |

## On LWR

The same keys draw the same part on an LWR site; see the Block card for where LWR differs.

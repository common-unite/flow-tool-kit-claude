# Cards 12: Outlined on mint

**Use it when:** Honest, low-pressure points (what we will and won't do).

**Why it works:** Outlined cards on mint feel calm and plain, suited to reassurance copy.

**Content it needs:** 3 items; a heading of about 9 words. If the client cannot supply it, pick another design.

| Prop | Property Editor | Value |
| --- | --- | --- |
| `background` | Background: Background | `#F3FAF4` |
| `bodyAlign` | Body: Alignment | `left` (Left) |
| `brandColor` | Background: Brand Color | `#2E844A` |
| `cardStyle` | Bullets: Card Style | `outlined` (Simple Border) |
| `headingAlign` | Heading: Heading Alignment | `left` (Left) |
| `hoverStyle` | Motion: Hover | `lift` (Lift) |

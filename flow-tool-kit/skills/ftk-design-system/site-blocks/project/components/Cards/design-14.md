# Cards 14: Joined on stripes

**Use it when:** Four short items as a band (four ingredients, four steps without numbers).

**Why it works:** Four joined cards on a striped light ground make a compact band.

**Content it needs:** 4 items. If the client cannot supply it, pick another design.

| Prop | Property Editor | Value |
| --- | --- | --- |
| `background` | Background: Background | `#EEF1F4` |
| `backgroundTexture` | Background: Texture | `stripes` (Stripes) |
| `bodyAlign` | Body: Alignment | `left` (Left) |
| `brandColor` | Background: Brand Color | `#53B95B` |
| `cardStyle` | Bullets: Card Style | `joined` (Joined) |
| `hoverStyle` | Motion: Hover | `lift` (Lift) |

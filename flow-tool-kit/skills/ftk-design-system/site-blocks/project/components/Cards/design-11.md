# Cards 11: Split, joined

**Use it when:** A principle with three supporting points.

**Why it works:** The heading sits beside three joined cards, so the principle and its points read as one block.

**Content it needs:** 3 items; a heading of about 5 words. If the client cannot supply it, pick another design.

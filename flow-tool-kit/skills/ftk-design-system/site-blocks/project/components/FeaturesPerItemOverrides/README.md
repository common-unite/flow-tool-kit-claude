# Features: Per-item overrides

One feature of the site design blocks shown across several designs: per-item overrides. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

One card in a set must stand out (a recommended option, a featured program).

## The decision it settles

Which item gets its own color or style, and why. Override one item at most; the rest keep the block's settings.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 1 block, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `cards` | 1 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `cardStyle` | `flat` |
| `columns` | `3` |
| `hoverStyle` | `lift` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

# Features: Icon styles

One feature of the site design blocks shown across several designs: icon styles. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

Cards carry icons and you are choosing how strong the icons are.

## The decision it settles

`iconStyle`: plain for quiet lists, tile for a strong colored marker without photos, circle for a softer marker.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 3 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `cards` | 3 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `cardStyle` | `outlined` |
| `columns` | `3` |
| `hoverStyle` | `lift` |
| `iconStyle` | `circle`, `plain`, `tile` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

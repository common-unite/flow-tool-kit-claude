# Features: Dark backgrounds

One feature of the site design blocks shown across several designs: dark backgrounds. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

A page needs a deep brand-color section and you want to see how each block reads on it.

## The decision it settles

Which blocks go on the deep color. Stats, closing bands, steps and pricing read best dark; long text and forms read best light.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 8 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Settings these designs use

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

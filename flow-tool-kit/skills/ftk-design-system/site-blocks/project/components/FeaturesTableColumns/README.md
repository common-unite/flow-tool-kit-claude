# Features: Table columns

One feature of the site design blocks shown across several designs: table columns. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

A Comparison Table is needed and the column set is undecided.

## The decision it settles

How many columns, which one is the label column, and whether values are text or small badges. Four columns fit at phone width; more need shorter values.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 7 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `table` | 7 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

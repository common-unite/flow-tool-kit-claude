# Features: Borders

One feature of the site design blocks shown across several designs: borders. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

Cards need more separation or a stronger frame on a busy page.

## The decision it settles

`borderWidth` on the block: a heavier border reads as a panel; leave it at 0 when the card style already frames the content.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 3 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `cards` | 3 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `borderWidth` | `8` |
| `cardStyle` | `clean` |
| `columns` | `2` |
| `hoverStyle` | `lift` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

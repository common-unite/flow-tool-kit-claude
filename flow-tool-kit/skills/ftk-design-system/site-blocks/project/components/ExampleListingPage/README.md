# ExampleListingPage

A listing page: many records of one kind, here every open funding opportunity of a community fund, on the Customer Service theme.

**Built from:** `Page` (`layout: "customerService"`), a full-width `Hero`, an 8/4 `Section` with a `Repeater` of Media Top record cards beside a `Callout` and `RichContent`, and a `StatsBar`. The same page shape `/design-to-blocks` produces for a listing.

Use it as the starting point for a client's list of programs, opportunities, events or volunteer shifts: swap the cards' fields for the object's own, and keep the help column beside the list.

## On LWR

On an LWR site the conversion scripts place the same Sections and blocks in the Build Your Own (LWR) layout. The Customer Service header is Aura only.

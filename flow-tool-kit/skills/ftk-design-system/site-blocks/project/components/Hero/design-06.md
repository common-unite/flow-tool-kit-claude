# Hero 06: Crosshatch statement

**Use it when:** A program with no single action yet (mentoring, a pilot), where the promise itself is the content.

**Why it works:** No image and no buttons: a strong headline on a textured navy ground, with badges for the two facts that matter. The wipe entrance gives it presence without media.

**Content it needs:** 2 badges; a heading of about 12 words. If the client cannot supply it, pick another design.

| Prop | Property Editor | Value |

| `background` | Background: Background | `#032D60` |
| `backgroundGradient` | Background: Gradient | `off` (Off) |
| `backgroundTexture` | Background: Texture | `crosshatch` (Crosshatch) |
| `badgePosition` | Badges: Badge Position | `top` |
| `bodyAlign` | Body: Alignment | `left` (Left) |

# ExampleChildRecordPage

A child record page: a record that belongs to a parent, here one application under the fund, on the Customer Service theme.

**Built from:** a short `Hero` naming the application; an 8/4 `Section` with the application's `FormSlot` (the Grant Application Form Template, designed in the FlowToolKit Forms design system) beside its status `Facts` and a Header Band `RecordCard` for the parent fund; and `Steps` for what happens next. The same page shape `/design-to-blocks` produces for a child record.

## On LWR

On an LWR site the conversion scripts place the same Sections and blocks in the Build Your Own (LWR) layout. The Customer Service header is Aura only.

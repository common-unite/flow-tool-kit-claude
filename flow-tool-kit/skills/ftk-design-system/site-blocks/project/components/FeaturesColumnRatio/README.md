# Features: Column ratio

One feature of the site design blocks shown across several designs: column ratio. From the demo site's showcase home page, where each chapter shows one setting's whole range.

## Use it when

A heading and intro should sit beside the cards rather than above them.

## The decision it settles

`arrangement: "split"` and how wide the heading side is. Use split when there are two to four items or the intro is long.

How this fits the whole page: `Choosing blocks`.

**From a test site:** 3 blocks, drawn by the package's own `siteDesignBlock` exactly as stored on the site.

## Blocks

| Type | Count |
| --- | --- |
| `cards` | 3 |

## Settings these designs use

The values on this card. Start a design from these, not from a block's defaults.

| Setting | Values used |
| --- | --- |
| `arrangement` | `split` |
| `bodyAlign` | `left` |
| `cardStyle` | `flat` |
| `columns` | `2` |
| `headingAlign` | `left` |
| `hoverStyle` | `lift` |

## Use it

Copy a section into a page design and change the words and images; keep the settings that give it its look. Every block key and value here is valid in the package (the props check passes on this card).

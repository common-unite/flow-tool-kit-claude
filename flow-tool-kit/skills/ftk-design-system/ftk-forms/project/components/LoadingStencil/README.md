# LoadingStencil

The grey placeholder a Form Template shows while its prefill flow runs, plus the brand spinner.

**Maps to:** `formLoadingStencil` (two header bars over two boxes of pulsing input shapes). `Spinner` is `lightning-spinner` size large, variant brand: the template's blocking spinner while it saves or moves between pages.

## Props
- `LoadingStencil`: none.
- `Spinner`: `size`, `alternativeText`, `inline` (sits in the flow; by default it covers its parent with a white wash).

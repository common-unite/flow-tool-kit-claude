# Backgrounds

The background photos packaged with FlowToolKit as Content Assets. Each file name is the Content Asset API name, so a design that uses `Background_Forest_Sunbeams.jpg` sets the image asset to `Background_Forest_Sunbeams` in the org. Copies here are resized to 1280px wide for previews, with the camera and stock-library metadata removed; the package holds the 2400px originals.

Use them for Banner and header images, Display Image sections and record card media.
